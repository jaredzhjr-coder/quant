# 展示与讲解指南

## 30 秒介绍

这个项目研究配对交易在成交延迟和交易成本下的行为。我把重点放在样本外
研究流程、资金核算和防止未来数据泄漏上。当前报告用有明确生成机制的模拟
数据验证程序，不把它当成真实市场 alpha。下一步是接入有来源记录的真实
行情，并加入训练期协整筛选、独立最终留出集和更真实的成交约束。

## 推荐演示顺序

1. 展示 README 和报告，先说明模拟数据及研究问题。
2. 解释形成窗口与交易窗口，指出训练结束日期早于交易开始日期。
3. 解释 t-1 信号、t 成交、t 到 t+1 收益为什么不能混用。
4. 展示未来数据扰动测试，以及持仓与收益核算测试。
5. 展示成本敏感性，说明零交易成本场景仍然收取借券费用。
6. 主动讲局限：没有验证真实 alpha、没有协整显著性筛选、没有容量模型。

## 应该能自己回答的问题

- 为什么用对数回归？为什么 beta 不是天然的市场中性系数？
- 回归残差看起来均值回复，与通过协整检验有什么区别？
- 今天收盘才知道的信号，为什么不能赚到今天收盘前的收益？
- 固定目标权重为什么每天也会产生再平衡成本？
- 训练窗口、退出阈值和最大持仓时间变化后，结论是否稳定？
- 为什么有序列相关时，普通 Sharpe 和独立抽样置信区间可能误导？
- 为什么在预先设定均值回复的模拟数据上赚钱不能证明有效策略？
- 如果相关关系永久失效、借券被召回，系统会怎样？

## 提交给招聘方之前

先亲自运行、理解并修改至少一个实验。保留结果不好的实验，清楚区分框架
验证与真实市场研究。可以说明使用了 AI 辅助开发，但应能独立解释所有核心
代码和假设，不要声称完成了尚未做过的实盘、真实数据研究或显著性检验。

项目可以展示工程与研究习惯，但不能保证满足某家公司的招聘标准。
